An ultra-modern, production-grade **MERN Stack** Web Application & PWA designed exclusively for the executive founders of **Weblets®** (`weblets.bond`) and **StackAdda™** (`stackadda.me`).

---

## 🚀 Quick Start Guide

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev   # or: node server.js
```
- Server starts on **`http://localhost:5000`**
- Health endpoint: `http://localhost:5000/api/health`
- Operates with MongoDB URI or automatic high-performance persistent fallback store (`backend/data/store.json`).

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
- Client starts on **`http://localhost:5173`** (or `5174`)
